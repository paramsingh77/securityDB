# Production Screenshot Capture Checklist

Screenshots should document the current app so the rebuilt UI can match the real workflows.

## Pages To Capture

- Login screen.
- Admin dashboard.
- Visitor check-in list, filters, pagination, new check-in modal, checkout state.
- Event reporting list, add form, edit modal, delete confirmation if present.
- Incident reporting filters, list, view screen, new incident form.
- User management list, search, add user modal, delete confirmation.
- Notification bell/dropdown if it exists.

## Before Capture

- Use a test account if available.
- Use fake/redacted data where possible.
- Avoid screenshots that expose real visitor names unless the hospital approves it.
- Capture desktop Chrome size similar to the security desk workstation.

## What I Need

- Production URL.
- Login credentials for a test/admin account.
- Any MFA/VPN instructions.
- Permission to capture screenshots of real screens.
